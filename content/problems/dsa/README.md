Two Sum is reused; the other 14 entries expand the catalog. The existing LRU
Cache problem remains available separately, for 16 DSA problems in total.
All 15 curated entries include the `blind-75` topic; LRU Cache does not.
Search for `blind 75` to show this collection and use Pick Random within those results.
See the [Blind 75 author's practice catalog](https://www.techinterviewhandbook.org/grind75/)
for the broader practice collection. Statements and examples here are authored
for OpenMock; these files contain no reference solutions.

All entries use category `algorithms`, the `dsa` interview definition, and the
existing Java code workspace. Linked-list and tree starters include their node
types so candidates can work in a single file.

Difficulty describes the problem, while target level remains a session setting.
The DSA definition supports Junior, Middle, Senior, Staff, and Principal. Each
problem's hidden `# Interviewer Context` supplies level-sensitive assessment
guidance without revealing a full solution. Easy problems may provide only
limited evidence at advanced levels; assess only demonstrated competencies.

Catalog filtering uses category, difficulty, and topics. Level selection in
interview setup applies to every listed problem; it does not exclude catalog
entries. Pick Random operates on the currently filtered results.
