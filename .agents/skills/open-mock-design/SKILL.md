# OpenMock Design System

OpenMock follows a Vercel/Geist-inspired design language.

The interface should feel precise, minimal, technical and intentionally
designed for software engineers.

## Typography

Use Geist Sans as the default typeface.

Use Geist Mono for:
- code
- technical identifiers
- keyboard shortcuts
- timers
- numeric metrics where fixed-width alignment improves readability

Typography should follow the Geist model:

### Headings

Hero:
- 48–64px
- font-weight: 600
- tight line-height
- negative letter spacing

Page title:
- 32px
- font-weight: 600
- tight tracking

Section title:
- 24px
- font-weight: 600

Card title:
- 16px
- font-weight: 600

### Labels

Primary UI label:
- 14px
- medium/semibold

Secondary UI label:
- 13px

Tertiary UI label:
- 12px

Labels should use compact line-height.

### Copy

Large marketing copy:
- 20px

Normal body:
- 14px
- relaxed line-height

Secondary copy:
- 13px
- muted foreground

Do not use arbitrary font sizes when an existing typography level fits.

## Typography principles

- Prefer strong hierarchy through size and weight.
- Use tight tracking for large headings.
- Use compact typography in application UI.
- Marketing pages may breathe more.
- Avoid excessive bold text.
- Avoid oversized SaaS hero typography.
- Use tabular numbers for timers, scores and metrics.
